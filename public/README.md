# public/ — copied as is

Files here are copied into `dist/` untouched: no hashing, no rewriting, no
bundling. That is the whole reason to use it, and it is also why almost nothing
belongs here.

Use `public/` only for files that need a **stable, predictable name**:

- `favicon.ico`, `apple-touch-icon.png`
- a portal thumbnail or og image, if a fixed URL is wanted
- anything a third-party script fetches by a hard-coded path

Everything else — models, textures, atlases, audio, fonts — goes in
`src/assets/`, where it gets a content hash and can be cached forever. A file
here has no hash, so a changed asset keeps its old name and players keep the
stale copy until their cache expires.

`public/packs/` is generated by `@vibe/pipeline/src/assets/packs.ts` (`npm run packs`) and gitignored.
